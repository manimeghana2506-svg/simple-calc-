## PeachCalc 

A simple, functional calculator web application built with pure HTML, Vanilla CSS, and JavaScript, designed with a warm peach-and-chocolate-brown aesthetic.

### ✨ Features
- **Design Palette**: Warm cream, soft peach, terracotta, and chocolate brown.
- **Arithmetic Operations**: Addition (+), Subtraction (-), Multiplication (×), and Division (÷).
- **Error Handling**: Friendly message for division by zero (`Cannot divide by 0`).
- **Keyboard Support**: Full numeric keypad and operator keyboard shortcuts.
- **Responsive Layout**: Designed for seamless use across desktops, tablets, and mobile screens.

### 🚀 Getting Started
Simply open `index.html` in any web browser. No installation or build steps required.
